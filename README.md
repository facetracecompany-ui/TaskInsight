## Что это

**TaskInsight** — лёгкая замена стандартному диспетчеру задач. Живёт в системном трее, открывается в отдельном окне и показывает нагрузку на **процессор, память, видеокарту, диски и сеть** в разрезе каждого процесса. Дополнительно ведёт **журнал нагрузки**, чтобы можно было разобраться, что тормозило компьютер час или три дня назад.

Не нужна установка зависимостей и .NET — это один исполняемый файл.

## Возможности

### Мониторинг в реальном времени
- Карточки по ЦП, памяти, GPU, диску и сети. В каждой указано, **какой процесс сейчас нагружает больше всех**
- Загрузка каждого ядра процессора
- Таблица процессов: ЦП, память, чтение и запись диска, потоки, сетевые соединения, GPU, время запуска
- Поиск, сортировка по любому столбцу, группировка по имени, скрытие простаивающих процессов
- Общая информация: имя компьютера, аптайм, число процессов и потоков
- Кнопка «Пауза», чтобы остановить таблицу и спокойно рассмотреть данные

### Подробности о процессе
Клик по процессу открывает панель с:
- путём к exe, командной строкой и рабочей папкой
- родительским и дочерними процессами
- приоритетом и состоянием
- **сетевыми соединениями** (TCP/UDP, локальный и удалённый адрес, статус)
- списком **открытых файлов**

Действия: **завершить**, **завершить дерево процессов**, **приостановить**, **возобновить**, скопировать путь. Системные процессы защищены от случайного завершения.

### Журнал нагрузки
Каждые 5 секунд программа записывает, какие процессы были заняты, и хранит историю **14 дней**.
- График по ЦП, памяти, GPU, диску или сети
- Период: 15 минут, 1 час, 6 часов, 24 часа, 7 дней или всё
- **Пики нагрузки** — когда и какой процесс «взлетел»
- Поиск по имени, пути и команде
- **Экспорт в CSV** и быстрый доступ к папке с логами

### Диски: кто держит файлы
Выберите диск и увидите, **какие процессы держат на нём открытые файлы**. Это помогает, когда Windows пишет «файл используется другим процессом», а какой именно, непонятно, или когда флешку не удаётся безопасно извлечь.

### Удобство
- Иконка в трее, открытие по клику
- Автозапуск вместе с Windows (галочка в меню трея)
- Повторный запуск не плодит копии, а показывает уже открытое окно
- Тёмный аккуратный интерфейс

## Установка

1. Откройте страницу [**Releases**](../../releases/latest)
2. В блоке **Assets** скачайте `TaskInsight.exe`
3. Запустите. Установка не требуется

> Для завершения и приостановки системных или чужих процессов запускайте TaskInsight **от имени администратора**. Без этого Windows ответит «Отказано в доступе».

> Windows SmartScreen может предупредить о неизвестном издателе: файл не подписан цифровой подписью. Нажмите «Подробнее» → «Выполнить в любом случае».

## Как это работает

TaskInsight запускает **локальный сервер** на `127.0.0.1` (только ваш компьютер, наружу ничего не открывается) на случайном порту с одноразовым ключом доступа. Интерфейс открывается в окне Microsoft Edge или Google Chrome в режиме приложения, а если их нет, то в браузере по умолчанию. Данные не отправляются в интернет.

| Что | Где |
|---|---|
| Журнал нагрузки | `%APPDATA%\TaskInsight\logs` |
| Служебные данные запущенного экземпляра | `%APPDATA%\TaskInsight\instance.json` |

## Сборка из исходников

Нужен [Go](https://go.dev/dl/) и Windows.

```powershell
git clone https://github.com/facetracecompany-ui/TaskInsight.git
cd TaskInsight
go build -ldflags "-H=windowsgui" -o TaskInsight.exe .
```

Структура проекта:

| Файл | Назначение |
|---|---|
| `main.go` | Запуск, локальный HTTP-сервер, API |
| `sampler.go` | Сбор метрик: ЦП, память, GPU, диски, сеть, процессы |
| `details.go` | Подробности о процессе и действия над ним |
| `diskfiles.go` | Поиск открытых файлов по дискам |
| `logger.go` | Журнал нагрузки, отчёты и пики |
| `tray.go` | Иконка в трее и автозапуск |
| `web/index.html` | Интерфейс |

Основные библиотеки: [gopsutil](https://github.com/shirou/gopsutil), [systray](https://github.com/energye/systray).
